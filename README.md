# utils

一些独立的小工具。每个工具放在自己的目录中，目录内提供使用说明、源码和可直接下载的成品。

## 工具列表

| 工具 | 用途 | 下载 |
| --- | --- | --- |
| [01 · 模拟输入小助手](01-模拟输入小助手/README.md) | 将 UTF-8 文件内容模拟为键盘输入到 Windows 窗口 | [Windows 便携版 ZIP](01-模拟输入小助手/release/模拟输入小助手.zip) |

下载便携版后解压，得到单个 `模拟输入小助手.exe`，双击即可运行（不需要 Python，也不需要 .NET；若被 SmartScreen 拦截，点“更多信息 → 仍要运行”即可）。使用方法、源码运行方式和打包方式见[工具说明](01-模拟输入小助手/README.md)。

程序会自检 Windows 完整性级别：如果 exe 放在受控目录（文件带 Low 完整性标签），主按钮会显示“无法输入”并提示原因——把 exe 复制到桌面等普通目录即可。
