# utils

一些独立的小工具。每个工具一个目录，目录里是源码、图标、打包脚本和可下载的成品。

| 工具 | 作用 | 下载 |
| --- | --- | --- |
| [01 · 模拟输入小助手](01-模拟输入小助手) | 把 UTF-8 文件的内容模拟成键盘输入，逐字打进当前窗口（支持拖拽文件、暂停/F8、停止/F9、虚拟机控制台扫描码） | [Windows 便携版 ZIP](01-模拟输入小助手/release/模拟输入小助手.zip) |

下载后解压，得到单个 `模拟输入小助手.exe`，双击即可运行：不需要 Python，也不需要 .NET。exe 未签名，若被 SmartScreen 拦截，点「更多信息 → 仍要运行」即可。详细用法见压缩包内的 `使用说明.txt`。

想自己构建：进入工具目录，按 [package_portable.py](01-模拟输入小助手/package_portable.py) 顶部的三行命令操作（建 venv、装 PyInstaller、运行脚本），产物写在该目录的 `dist/` 并自动同步到 `release/`。
